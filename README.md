|-------|----------|

| Avatar | Videos avec avatar parlant (HeyGen) |
| Resume | Resume de contenus longs |
| Juridique IA | Conseil juridique et legal |
| Image | Generation d'images depuis prompts |
| Agent Mail | Gestion des emails |
| Calendrier Agent | Gestion du calendrier |
| Web Agent | Navigation et recherche web |
| Agent Contacts | Gestion du carnet d'adresses |
| Agent PDF | Creation et manipulation de PDF |
| Agent RAG | Recherche dans la base de connaissances |

| Docteur | Questions medicales et sante |
| Think | Raisonnement et reflexion |
| Calculator | Calculs mathematiques |

| OpenWeatherMap | Meteo en temps reel |

## Import

1. Ouvrir n8n
2. Aller dans **Workflows > Import from File**
3. Selectionner `agent-nexusflow.json`
4. Configurer les credentials necessaires (Telegram, OpenRouter, Anthropic, ElevenLabs, Google Sheets, Redis)

## Notes

- Les credentials ont ete retirees du fichier JSON pour des raisons de securite
- Vous devez configurer vos propres credentials apres import
